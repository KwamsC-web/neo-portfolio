Case study / Capstone, 2026

Web-Based Barangay Information and Socio-Economic Profiling System

Built for the Office of Barangay Dampol 2nd-A, Pulilan, Bulacan

Overview

A full-stack web application that replaces paper and spreadsheet records in a barangay office. Staff can register residents and households, record socio-economic data, see households on a map and produce reports.

The problem

The barangay office kept resident and household records on paper and spreadsheets. The system gives staff one place to register, search and verify those records and to produce reports from them.

My contribution

I was the group leader and developer. I designed the database, wrote the PHP back end and the JavaScript front end, and built the responsive layouts.

Key features

  • Dashboards for population, household and sector statistics
  • Resident and household profiling with search and filtering
  • Socio-economic profiling: income, employment and education
  • Verification of 4Ps, PWD, senior citizen and solo parent records
  • Household map by purok, built with Leaflet
  • Demographic, household and socio-economic reports with PDF and Excel export
  • Role-based access for admin, secretary and staff accounts
  • Activity logs, archives, and data backup and restore

Status

2026 capstone project. No live demo or public repository is linked yet.

  • MySQL
  • JavaScript

  • PHPMailer

Case study / Solo project, 2026

Thesara: Thesis Planning App for Student Groups

Built for college students and research groups in the Philippines

Overview

An Android app and website that help a student group plan and track a thesis from proposal to defense. It is free to use, with an optional Premium plan.

The problem

A thesis involves many moving parts: chapters, group tasks, deadlines, adviser feedback, references and defense preparation. Thesara keeps them together in one place for the whole group.

My contribution

I was the solo developer. I designed and built the app, the website, the database and the server functions that send emails and push notifications.

Key features

  • Chapter and section progress, from proposal to final manuscript
  • Group tasks with owners and due dates; overdue work is flagged
  • Calendar of deadlines, consultations and milestones, with reminders
  • Invitations for groupmates and the adviser, comments, meeting records and document reviews
  • Documents, notes and references, with citations in APA, MLA and IEEE
  • Defense preparation: countdown, checklist, question cards and a practice timer
  • Word manuscript export

Status

An Android app and a website, both built by me. The website is linked below.

  • React Native
  • Expo
  • Supabase
  • PostgreSQL
  • Cloudflare Pages

Case study / Group project, 2025

Picture Puzzle

Overview

A sliding picture puzzle for Windows. The game cuts an image into tiles, shuffles them, and times how long the player takes to put the picture back together.

My contribution

This was a two-person group project. I was the coder: I wrote the game logic, including the image cropping, tile shuffling and win check. My teammate designed the interface.

Key features

  • Splits an image into tiles and shuffles them on a 3 by 3 board
  • Two levels, each with its own picture
  • Players can drag in their own image to use as the puzzle
  • Timer, restart button and a leaderboard sorted by fastest time

Built with

  • .NET Framework

Case study / Group project, 2025

Turn-Based Battle Game

Overview

A two-fighter battle game for Windows. The player and a computer opponent take turns attacking until one fighter's health reaches zero.

My contribution

This was a two-person group project. I was the coder: I wrote the Player class, an EnemyPlayer class that inherits from it, and the turn logic. My teammate designed the interface.

Key features

  • Fighters have health, attack, defense and mana, shown as live bars
  • Two moves: a normal attack, and a skill that costs mana and deals double damage
  • Attacks can miss, so each turn has some risk
  • A computer opponent that chooses between attacking and using a skill
  • Two maps, each with its own pair of fighters

Built with

  • C#
  • Windows Forms
  • .NET Framework
